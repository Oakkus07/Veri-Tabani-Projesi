# Hastane Otomasyonu Veritabanı Projesi

Bu proje, bir hastane otomasyon sistemi prototipinin ilişkisel veri tabanı tasarımını içermektedir. Proje kapsamında hastane işleyişine uygun Varlık-İlişki (ER) diyagramı kuralları (Doktor-Poliklinik, Hasta-Tahlil ilişkileri vb.) baz alınarak gerekli tablolar ve ilişkiler kurgulanmıştır.

## 🚀 Kullanılan Teknolojiler
* **SQL**
* **MySQL**

## 📂 Proje İçeriği
* `schema.sql`: Poliklinik, Doktor, Hasta, Muayene, Laboratuvar, Tahlil, Servis ve Hemşire varlık kümelerine ait tabloların oluşturulmasını ve aralarındaki ilişkileri (1:N, N:M) tanımlayan veritabanı şeması.

## 👥 Proje Ekibi
Bu proje, veri tabanı projesi ödevi kapsamında aşağıdaki 2 kişilik ekip tarafından geliştirilmiştir:

* **Oğuzhan Akkuş** - 455089
* **Furkan Ağır** - 455085
